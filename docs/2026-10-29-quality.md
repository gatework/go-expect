# Generic engine quality — 2026-10-29

Source: `feat/connector-unification`, baseline `3d3b1ef`. Local work only; no publication or dependency replacement.

## Changes and contracts

The OS polling pump now reuses one scratch block for small reads, copies compact independent events, and transfers exclusive ownership for large reads. RawConn error causes, PTY EOF normalization and the existing 10ms polling design are preserved.

Pure literal `All` trees use per-Expect leaf state to retain earliest hits and scan only new bytes plus boundary overlap. State resets after consumption; immutable Pattern values hold no operation state. Ordinary patterns retain their existing integer scan offsets; optional All state is created only when needed. Mixed trees and arbitrary regexps keep full-buffer matching, capture, UTF-8 and longest-match behavior.

The public Redactor returns independently owned bytes, avoids whole-chunk work buffers for safe input, reuses bounded suffix storage, and allocates masked output only when needed. The boundary fast path declines secrets longer than 256 bytes and uses the established general matcher: this bounds the new candidate-comparison cost without imposing a public secret-length limit. A repeated-prefix fixture checks a completed crossing match and conservative Finish masking. Overlapping/adjacent replacement runs, binary input and SetSecrets scopes remain covered by differential fuzzing.

`script/consumer` checks a disposable copy of this source module with `GOWORK=off`, readonly pinned external dependencies and an explicit no-replacement check. This is source-consumer evidence, separate from adoption of a published module version.

## Benchmark method

Apple M5, macOS arm64, Go 1.27.1. Samples run serially while other agents pause builds/tests. Each comparison has ten samples per named case, `-benchtime=100ms -benchmem`, with benchstat analysis. The clean baseline receives identical benchmark files. The unguarded long-boundary snapshot differs from the guarded candidate only by removal of the new length guard.

Raw samples and comparisons are saved under [benchmarks/2026-10-29](benchmarks/2026-10-29/). OS/idle source did not change during review follow-up; its original serial comparison remains separately labeled. Earlier broad results showed 27–50% faster literal All, 11–12% faster small/mid OS reads, and substantially lower safe redaction allocation; the final affected-path comparison supersedes earlier ordinary-pattern/redactor timing samples.

Keep memory categories separate: B/op is cumulative allocation; tail-cap-B is logical retained slice capacity; idle retained-B/session is a post-GC heap delta; peak RSS is a process high-water observation. A 1 MiB retained-tail workload previously measured 7.014 MiB → 1.000 MiB cumulative allocation and 16 → 10 bytes tail capacity. Single compiled-process fixed 100x RSS observations were 22,544,384 baseline and 16,990,208 candidate bytes; those are descriptive observations, not a significance claim.

[Affected-path comparison](benchmarks/2026-10-29/affected-benchstat.txt) compares the clean baseline with final guarded source; [long-boundary comparison](benchmarks/2026-10-29/long-boundary-benchstat.txt) includes baseline, the reproduced unguarded snapshot and the fix. The removed long-secret path took **49.3 ms/op** at N=65536, versus **286 us/op** with the guard. Increasing N from 4096 to 65536 multiplies final time by 16.1, versus 199 in the unguarded path: the bounded fallback restores the established scaling. The final fallback remains 4–8% slower than clean baseline for the measured long-rule cases because the new optimization checks precede the general matcher.

Tradeoffs remain explicit: matched Redactor chunk32 is +4.3% time/+12.4% allocation bytes; overlapping chunk32 is +1.5% time/+10.1% allocation bytes. Matched chunk1 is +1.9% time while allocating fewer bytes. Generic receive chunk1 is +1.5%; chunk32 is statistically unchanged. Ordinary literal chunk32 is +1.3%, while literal chunk1024 and both standalone regexp cases are unchanged. The prior +8% generic large-chunk timing did not persist after removing unnecessary All state from ordinary operations; final measurements show -5%, rather than claiming the earlier sample never happened.

## Remaining limits

The polling wakeup architecture remains unchanged. No regex truncation is introduced. Published dependency adoption and real devices remain separate verification steps. The full comparison artifacts retain slower workloads and allocation tradeoffs rather than relying on an aggregate geomean.
